Este vault es una carpeta de tu equipo, y cada nota es un archivo `.md` dentro de ella. Esta nota es solo un ejemplo: puedes editarla, renombrarla desde su título o borrarla.

## Dar formato

Mycelium usa Markdown, y lo que escribes toma formato mientras escribes.

- **Negrita** con `**dos asteriscos**` y *cursiva* con `*uno*`.
- Un título empieza con `#`; cuantos más `#`, más pequeño.
- El `código` va entre acentos graves.

## Tareas

- [x] Abrir Mycelium por primera vez
- [ ] Crear una nota nueva con **Ctrl+O**
- [ ] Enlazar esa nota desde aquí

## Callouts

> [!tip] Un callout destaca una idea
> Empieza con `> [!tip]`, `> [!info]` o `> [!warning]`, seguido de un título.

## Enlaces

Un enlace une dos notas: el título de la nota entre corchetes dobles. Este lleva a un encabezado de esta misma nota: [[#Dar formato]]. Para enlazar otra, escribe `[[` y elígela de la lista. Cada enlace es una línea en el grafo de conexiones.

## Etiquetas

Una etiqueta agrupa notas de temas distintos, estén en la carpeta que estén: #bienvenida. Para encontrarlas, busca `tag:bienvenida` en la búsqueda global.

## Moverse por Mycelium

| Para | Usa |
|---|---|
| Ir a una nota o crear una | **Ctrl+O** |
| Ejecutar un comando | **Ctrl+P** |
| Buscar en todas las notas | El ícono **Búsqueda global** del rail |
| Ver el grafo de conexiones | El ícono **Grafo de conexiones** del rail |
| Abrir la configuración | **Ctrl+,** |
| Abrir la ayuda | **F1** |

La ayuda explica todo lo demás: propiedades, tablas, lienzos, dibujos, el calendario y los atajos de teclado.
